# kechol/homebrew-tap

Homebrew tap for [kechol](https://github.com/kechol)'s tools.

## browser-review

[`browser-review`](https://github.com/kechol/browser-review) — browser annotations for local coding agents: point at an element, leave a comment, and let your agent fix the code behind it.

```sh
brew install kechol/tap/browser-review
```

## evalsig

[`evalsig`](https://github.com/kechol/evalsig) — statistics and signal detection for evaluation records.

```sh
brew install kechol/tap/evalsig
```

## heal

[`heal`](https://github.com/kechol/heal) — code health monitoring & maintenance via Claude Code hooks and skills.

```sh
brew install kechol/tap/heal
```

## kozo

[`kozo`](https://github.com/kechol/kozo) — personal software factory that runs on your own machine.

```sh
brew install kechol/tap/kozo
```

## kura

[`kura`](https://github.com/kechol/kura) — local knowledge management CLI with Japanese-aware hybrid search.

```sh
brew install kechol/tap/kura
```
